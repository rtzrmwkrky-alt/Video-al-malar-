# Video Çalışmaları

Sosyal medya için organik video içerik üretimi: **ElevenLabs** (seslendirme) + **Remotion** (video).

```bash
npm install
cp .env.example .env          # ELEVENLABS_API_KEY ekle
npm run voice -- --name ornek "Merhaba, bu ilk videomuz!"
npm run dev                   # Remotion Studio
```

Detaylar için [CLAUDE.md](./CLAUDE.md).
